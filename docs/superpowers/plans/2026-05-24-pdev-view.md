# pdev view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `pdev view`, an interactive Bubble Tea TUI that shows the current cell list and supports `j`, `k`, and `q`.

**Architecture:** Keep command parsing in `internal/app`, keep data loading in `internal/usecase`, and keep terminal UI logic in a dedicated adapter package. The usecase returns the cell slice from `.pdev/state.json`, and the adapter owns selection state, key handling, and rendering. `pdev ls` stays unchanged.

**Tech Stack:** Go 1.26, Bubble Tea, existing `internal/adapter/state` JSON state adapter, existing `internal/usecase` ports.

The `Update` method should respond to these keys:

```go
switch msg := msg.(type) {
case tea.KeyMsg:
	switch msg.String() {
	case "j":
		if m.Selected < len(m.Cells)-1 {
			m.Selected++
		}
	case "k":
		if m.Selected > 0 {
			m.Selected--
		}
	case "q":
		m.Quitting = true
		return m, tea.Quit
	}
}
```
