# pdev MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first Go CLI MVP for `pdev` with `create` and `remove` commands.

**Architecture:** DDD + Clean Architecture. Domain contains models and domain services. Usecase contains `CreateCellUseCase`, `RemoveCellUseCase`, and port interfaces. Adapters implement config/state/source/container/session/system behavior.

**Tech Stack:** Go 1.26, standard library, `gopkg.in/yaml.v3` for YAML parsing.

---

## File Structure

- `cmd/pdev/main.go`: CLI entrypoint and argument parsing.
- `internal/domain`: domain models and services.
- `internal/usecase`: create/remove usecases and port interfaces.
- `internal/adapter/config`: `.pdev.yml` YAML loader.
- `internal/adapter/state`: `.pdev/state.json` store.
- `internal/adapter/source`: source workspace creation.
- `internal/adapter/container`: Docker CLI adapter.
- `internal/adapter/session`: tmux adapter.
- `internal/adapter/system`: command runner and filesystem helpers.
- `internal/app`: dependency wiring.
